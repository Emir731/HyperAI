Built for local AI

Useful tools, with privacy at the core.

A focused interface for running and managing local language models.

⌘

Local GGUF models

Select a model stored on your device. Model files are not bundled with the app or uploaded by Hyper AI.

◈

Text and image input

Choose a local image and include it with your prompt when using a compatible multimodal model.

⏵

Streaming responses

See generated text as it arrives and cancel an active response when you need to.

▤

Conversation controls

Create, rename, and delete chats. Edit, copy, or remove individual messages.

⚙

Generation settings

Adjust context length, temperature, output token limit, and CPU thread settings.

文

Multilingual interface

Core chat and model flows include English, Turkish, and Russian labels.

Compatibility note: Hyper AI's local inference runtime is designed for native Android and iOS devices. This GitHub Pages website is the project homepage; it does not run the local GGUF chat engine in your browser.
Getting started

Bring your own model.

Hyper AI keeps model selection in your hands.

Get the app source

Open the repository to review the Flutter project and its build instructions.

Choose compatible files

Select a GGUF model and, for supported vision models, its matching multimodal projector.

Run locally

Load the model on your device and start a conversation. Performance depends on your hardware and model.
